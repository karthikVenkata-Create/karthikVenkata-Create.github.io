Costco Equity Valuation (SELL, $511 target)

Built a Python valuation model for Costco that pulls live market data, runs a DCF and a reverse DCF, and stress-tests the result with 10,000 Monte Carlo simulations. Every run is saved to a SQL database. My call is SELL with a $511 target. The price works only if Costco grows about 10% a year for another two decades, and even if everything goes right, a buyer at $992 earns only about 1.6 points more a year than a Treasury bond. Most analysts disagree, and the write-up explains why.

FP&A Budget Variance Analysis

Analyzed $28.2M of 2024 operating spend across 8 departments and 12 months. The plan looked 99.8% accurate, but only because overspends and underspends cancelled out. Counting every miss, accuracy was 95.7%, or $1.21M of misses, and 7 of 96 department-months broke my materiality rule (over $25K and over 5%). I first built this in Excel, found my own headline didn't hold up, rebuilt the workbook, then automated it as an Alteryx Designer workflow. It reads each department's file, logs every dropped row with its reason, raises an error if the totals don't tie out, and matches the workbook to the dollar.

Multi-Stock Risk & Return Analysis: 5 Auto Stocks

Tested whether optimizing a portfolio of five auto stocks (Tesla, Toyota, Honda, BMW, Geely) beats just splitting the money equally, using 3,932 trading days from 2010 to 2026. Rebalancing every year didn't earn more than buy-and-hold (23.9% vs 29.4% a year), but it cut the worst drop from 71% to 39%. Then I ran a walk-forward test where each year's weights only use the previous three years of data. Max-Sharpe roughly tied equal weight on return per unit of risk while trading twice as much, and min-variance badly lagged. Built in R and visualized in three Tableau dashboards. This started as an Excel project and got rebuilt twice.

Commodity Hedging & Risk Simulation

Rebuilt an eight-round hedging game from my Fall 2025 weekly decision memos, where I hedged a producer's 100,000 units a round with swaps, zero-cost collars and a floating slice. My hedges cost 4.6% of revenue ($74.7M vs $78.3M unhedged) and cut volatility 30%. Looking only at what happened, the hedges seemed unnecessary, because the unhedged book never hit the bankruptcy line either. So I priced every collar with Black-76 and ran each round's position through 10,000 Monte Carlo scenarios at the volatility the game actually had. Unhedged, there was about a 25% chance of the $20M bankruptcy penalty each round, and my hedges cut that to about 1%. The cost was the investment: the hedges lowered the odds of funding it from 26% to 18%, which traced back to where I set my strikes. The Python pipeline exports a multi-tab Excel audit report with live pricing formulas.

Live Multi-Currency Converter & Process Mining

Built a live currency converter in Celonis Studio. A View sends a base currency, an amount and up to six target currencies to an Action Flow, which loops through each target, calls the Frankfurter FX API and sends every conversion back in one response. It worked for one to five currencies and then failed when all six were picked. The run logs showed why: the list included the base currency itself, so the flow asked the API to convert CAD into CAD, got a 422 "bad currency pair" error, and the whole run rolled back. I added a router with a validation filter before the API call so any target that matches the base gets skipped, then deployed the fix and re-tested with all six selected. The converter started from the Celonis Master Data Wrangling case study; the router and the fix are my additions. In progress: a Procure-to-Pay process mining dashboard on a 500-order event log I generated in Python, with problems like invoices arriving before purchase orders, skipped approvals and late payments built in for the analysis to find.
